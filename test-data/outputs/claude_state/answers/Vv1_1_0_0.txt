Grover's algorithm on 4 items (2 qubits), searching for the marked item |11>

Setup
With N = 4 items we need n = 2 qubits. The four basis states |00>, |01>, |10>, |11> stand for the four items. The marked item is |11>. The optimal number of Grover iterations is about (pi/4)*sqrt(N) = (pi/4)*2 ≈ 1.57, which rounds down to 1. For N = 4, a single iteration finds the marked item with certainty.

Step 1: Start in |00>
Amplitudes: |00> = 1, |01> = 0, |10> = 0, |11> = 0.

Step 2: Create a uniform superposition (Hadamard on both qubits)
H⊗H|00> = |s> = (1/2)(|00> + |01> + |10> + |11>)
Each item now has amplitude 1/2, so a measurement at this point would give each item with probability (1/2)^2 = 1/4 (just random guessing).

Step 3: Oracle (mark the target by flipping its phase)
The oracle applies U_f|x> = (-1)^f(x)|x>, where f(x) = 1 only for x = 11. For the target 11 this is just a controlled-Z (CZ) gate, which multiplies |11> by -1 and leaves the other states unchanged:
(1/2)(|00> + |01> + |10> - |11>)
The probabilities have not changed yet (all still 1/4); only the sign of the marked amplitude is different. The diffusion step turns that sign difference into a difference in amplitude size.

Step 4: Diffusion operator (inversion about the mean)
The diffuser is D = 2|s><s| - I. Its effect on each amplitude a is a -> 2*(mean) - a.
- Mean of the amplitudes: (1/2 + 1/2 + 1/2 - 1/2) / 4 = 1/4
- Unmarked states: 2*(1/4) - 1/2 = 0
- Marked state |11>: 2*(1/4) - (-1/2) = 1
Resulting state: |11>, i.e. amplitudes (0, 0, 0, 1).

Step 5: Measure
Measuring gives 11 with probability 1^2 = 1 (100%) in an ideal, noise-free circuit.

Geometric picture
Write |s> = sin(theta)|w> + cos(theta)|w_perp>, where |w> = |11> and |w_perp> is the equal superposition of the three unmarked states. Here sin(theta) = 1/sqrt(N) = 1/2, so theta = 30 degrees. Each Grover iteration (oracle followed by diffusion) is two reflections, which together rotate the state by 2*theta = 60 degrees toward |w>. After k iterations the angle from |w_perp> is (2k + 1)*theta. With k = 1 that is 3*30 = 90 degrees, so the state lands exactly on |11>. A second iteration would overshoot to 150 degrees and lower the success probability to sin^2(150°) = 1/4, which is why you stop after one iteration.

Circuit (2 qubits)
1. H on q0 and q1                      (superposition)
2. CZ(q0, q1)                          (oracle for |11>)
3. H on both, X on both                (start of diffuser)
4. CZ(q0, q1)
5. X on both, H on both                (end of diffuser)
6. Measure both qubits -> 11

Steps 3 to 5 implement I - 2|s><s|, which equals the diffuser D up to a global phase of -1. A global phase cannot be observed, so the result is the same.

Why this matters
A classical search through 4 unsorted items needs on average 2.25 oracle queries if you check items one at a time (up to 3 queries to be certain, because the 4th can be inferred). Grover needs exactly 1 query here. In general Grover uses about (pi/4)*sqrt(N) queries instead of about N/2, a quadratic speed-up. N = 4 is a special case where the rotation lands exactly on the target. For most other N, the final success probability is high but slightly below 1.
