Grover's algorithm on 4 items (2 qubits), searching for the marked item |11>

Setup
With N = 4 items we need n = 2 qubits, whose basis states |00>, |01>, |10>, |11> label the four items. The marked item is |11>. Classically you would need on average about 2-3 queries (worst case 3) to find it. Grover's algorithm finds it with certainty using a single oracle query, because for N = 4 one Grover iteration happens to rotate the state exactly onto the answer.

Step 1: Initialize
Start in |00>.
Amplitudes: |00>: 1, |01>: 0, |10>: 0, |11>: 0

Step 2: Create an equal superposition
Apply a Hadamard gate to each qubit (H ⊗ H):
|s> = (1/2)(|00> + |01> + |10> + |11>)
Amplitudes: 1/2, 1/2, 1/2, 1/2
Each item has probability (1/2)^2 = 1/4, so measuring now would be no better than a random guess.

Step 3: Apply the oracle (mark the answer)
The oracle flips the sign (phase) of the marked state only:
O|x> = -|x> if x = 11, and |x> otherwise.
For |11> this is exactly a controlled-Z (CZ) gate, which multiplies |11> by -1 and leaves the other states unchanged.
State after the oracle: (1/2)(|00> + |01> + |10> - |11>)
Amplitudes: 1/2, 1/2, 1/2, -1/2
The probabilities are still all 1/4; the marking is hidden in the phase, so it cannot be seen by measuring yet.

Step 4: Apply the diffusion operator (inversion about the mean)
The diffuser D = 2|s><s| - I reflects every amplitude about the average amplitude: new amplitude = 2 x (mean) - (old amplitude).
Mean of the amplitudes = (1/2 + 1/2 + 1/2 - 1/2) / 4 = 1/4
- Unmarked states: 2(1/4) - 1/2 = 0
- Marked state |11>: 2(1/4) - (-1/2) = 1
State after diffusion: |11>
Amplitudes: 0, 0, 0, 1

Step 5: Measure
Measuring both qubits gives 11 with probability 1. The marked item is found after exactly one oracle call.

Circuit for the diffuser (2 qubits)
H on both qubits -> X on both qubits -> CZ -> X on both qubits -> H on both qubits.
(This implements the reflection about |s>, up to an irrelevant global phase.)
Full circuit: H H | CZ (oracle for 11) | H H, X X, CZ, X X, H H | measure.

Geometric picture (why one iteration is enough)
Think of the state as a vector in a 2-D plane spanned by the marked state |w> = |11> and the uniform superposition of the unmarked states |w'>. The starting state |s> makes an angle θ with |w'>, where sin θ = 1/sqrt(N) = 1/2, so θ = 30°.
- The oracle reflects the state about |w'>.
- The diffuser reflects it about |s>.
Two reflections together make a rotation by 2θ = 60° toward |w>. After k iterations the angle is (2k + 1)θ. For k = 1 this is 3 x 30° = 90°, which lands exactly on |w> = |11>. The success probability is sin^2((2k + 1)θ) = sin^2(90°) = 1.

Key points
- The oracle does not "reveal" the answer; it only flips its phase.
- The diffuser turns that phase difference into an amplitude difference by inverting about the mean, so the marked amplitude grows while the others shrink (constructive vs destructive interference).
- In general about (π/4)·sqrt(N) iterations are needed, which gives the quadratic speed-up over classical search. For N = 4 that is (π/4)·2 ≈ 1.57, which rounds to 1, and here one iteration is exact.
- Doing more iterations than needed rotates past the answer: a second iteration here would give angle 5θ = 150° and success probability sin^2(150°) = 1/4, which is no better than guessing.
