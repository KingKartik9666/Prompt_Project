1. Goal of the algorithm

Given a black-box function f: {0,1}^2 -> {0,1} that is promised to be either constant (same output for all 4 inputs) or balanced (outputs 0 on exactly 2 inputs and 1 on the other 2), Deutsch-Jozsa decides which case holds. It does this with a single query to the oracle, whereas a deterministic classical algorithm needs up to 2^(n-1) + 1 = 3 queries in the worst case for n = 2.

2. Steps

Example balanced function used throughout: f(x1 x2) = x1 XOR x2, so f(00) = 0, f(01) = 1, f(10) = 1, f(11) = 0.
Oracle: U_f |x>|y> = |x>|y XOR f(x)>, where x is the 2-qubit input register and y is a 1-qubit ancilla.
Notation: |+> = (|0> + |1>)/sqrt(2), |-> = (|0> - |1>)/sqrt(2), H = (1/sqrt(2)) [[1, 1], [1, -1]].

Step 1 - Initialise.
Put the two input qubits in |0> and the ancilla in |1>.
|psi_0> = |00>|1>

Step 2 - Apply H to all three qubits (H tensor H tensor H).
H|0> = |+>, H|1> = |->, so the input register becomes an equal superposition of all 4 inputs.
|psi_1> = (1/2)(|00> + |01> + |10> + |11>) |->
        = (1/2) SUM_x |x> |->

Step 3 - Query the oracle once (apply U_f).
Because the ancilla is |->, U_f |x>|-> = (-1)^f(x) |x>|-> (phase kickback: if f(x) = 1, |0> and |1> in the ancilla swap, which flips the sign of |->). The function value moves into the phase of the input register.
|psi_2> = (1/2) SUM_x (-1)^f(x) |x> |->
        = (1/2)( (+1)|00> + (-1)|01> + (-1)|10> + (+1)|11> ) |->
        = (1/2)(|00> - |01> - |10> + |11>) |->
Note that (1/2)(|00> - |01> - |10> + |11>) = |-> tensor |->, so
|psi_2> = |->|->|->
The ancilla is now unentangled and can be ignored.

Step 4 - Apply H to each of the two input qubits (H tensor H).
In general, H^(tensor 2)|x> = (1/2) SUM_z (-1)^(x.z) |z>, so the amplitude of |z> after this step is
a(z) = (1/4) SUM_x (-1)^(f(x) + x.z).
For z = 00: a(00) = (1/4)(1 - 1 - 1 + 1) = 0. This is the key fact: for any balanced f the |00> amplitude is exactly 0, and for any constant f it is +1 or -1.
For our specific f, H|-> = |1> on each input qubit, so
|psi_3> = |11> |->

Step 5 - Measure the two input qubits in the computational basis.

3. Final measurement result with probabilities

Final input-register state: |11>
P(00) = |a(00)|^2 = 0
P(01) = 0
P(10) = 0
P(11) = 1

The outcome is 11 with certainty. Decision rule: if the measured result is 00, f is constant; if it is anything other than 00, f is balanced. Since P(00) = 0 here, the algorithm reports "balanced" with probability 1 (in an ideal, noise-free circuit). A different balanced function would give a different non-zero outcome (for example, f(x1 x2) = x1 gives 10), but never 00.

On speedup: for n = 2 this is 1 quantum query versus 3 deterministic classical queries. The gap versus deterministic classical algorithms grows exponentially in n (1 versus 2^(n-1) + 1), but a randomized classical algorithm can decide the problem with a small constant number of queries and a small error probability, so there is no exponential speedup over bounded-error classical algorithms.

4. Common misconception

Deutsch-Jozsa does not "evaluate f on all inputs and read out every value in parallel" - the measurement only reveals a single global property (constant vs balanced) obtained through interference, and the individual values f(x) are never learned.
