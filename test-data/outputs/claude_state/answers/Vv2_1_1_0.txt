1. Goal of the algorithm
Grover's algorithm searches an unstructured list for an item that a "checker" function (the oracle) recognises as marked, here the item 11 among the four items 00, 01, 10, 11. It needs about (pi/4)*sqrt(N) checks instead of the roughly N/2 checks a classical search needs on average, which is a quadratic speedup, not an exponential one.

2. Steps
We use 2 qubits, because 2 qubits can represent 4 items. I write the state as a list of 4 amplitudes in the order (00, 01, 10, 11). The probability of measuring an item is its amplitude squared.

Step 1 - Initialise.
Both qubits start at 0.
State: (1, 0, 0, 0)
The system is definitely in 00.

Step 2 - Create an equal superposition (apply a Hadamard gate to each qubit).
Every item now has the same amplitude.
State: (1/2, 1/2, 1/2, 1/2)
Each item has probability (1/2)^2 = 1/4, so measuring now would just be a random guess.

Step 3 - Apply the oracle (mark the answer).
The oracle flips the sign of the amplitude of the marked item 11 and leaves the others alone. In bra-ket notation, it maps |11> to -|11>.
State: (1/2, 1/2, 1/2, -1/2), which is (1/2)(|00> + |01> + |10> - |11>)
The probabilities have not changed yet (still 1/4 each); only the sign of 11 is different.

Step 4 - Apply the diffusion operator ("inversion about the mean").
This is built from Hadamards, a phase flip on |00>, and Hadamards again. Its effect is to replace each amplitude a with (2 x mean - a).
Mean of the amplitudes = (1/2 + 1/2 + 1/2 - 1/2) / 4 = 1/4.
- For 00, 01, 10: 2(1/4) - 1/2 = 0
- For 11: 2(1/4) - (-1/2) = 1
State: (0, 0, 0, 1), which is |11>
For N = 4, one oracle call plus one diffusion step (one Grover iteration) is exactly the right amount; (pi/4)*sqrt(4) is about 1.57, which rounds to 1 iteration.

3. Final measurement result with probabilities
Measuring both qubits in the state |11> gives:
- |00>: 0%
- |01>: 0%
- |10>: 0%
- |11>: 100%
So the marked item 11 is found with certainty after a single oracle query, whereas a classical search over 4 items needs up to 3 queries in the worst case (about 2.25 on average if you stop early). The 100% holds for ideal, noise-free qubits; on real hardware noise lowers it, and I cannot give an exact figure because it depends on the device. Getting exactly 100% is also a special feature of N = 4 with one marked item. For larger N the success probability is high but usually not exactly 1.

4. Common misconception
Grover's algorithm does not "check all items at once and read out the answer" or give an exponential speedup; it slowly amplifies the marked item's amplitude through interference, which gives only a quadratic (sqrt(N)) speedup.
