A Bell state is a maximally entangled state of two qubits. The most common one is

|Phi+> = (|00> + |11>) / sqrt(2)

You can create it with just two gates: a Hadamard (H) followed by a CNOT.

Step-by-step

1. Start with both qubits in |0>:
   |psi0> = |0>|0> = |00>

2. Apply a Hadamard gate to the first qubit (the control). H maps |0> to (|0> + |1>)/sqrt(2), so:
   |psi1> = (|0> + |1>)/sqrt(2) ⊗ |0> = (|00> + |10>) / sqrt(2)
   The first qubit is now in an equal superposition, but the two qubits are still not entangled; the state can still be written as a product of two single-qubit states.

3. Apply a CNOT gate with qubit 1 as control and qubit 2 as target. CNOT flips the target only when the control is |1>:
   |00> -> |00>
   |10> -> |11>
   so
   |psi2> = (|00> + |11>) / sqrt(2) = |Phi+>

This final state cannot be written as a product of two single-qubit states, which is what makes it entangled. If you measure either qubit, you get 0 or 1 with 50% probability each, but the two results always agree: measuring 0 on one qubit means the other is 0, and measuring 1 means the other is 1.

Getting the other three Bell states

There are four Bell states in total. You get them by changing the starting input (or, equivalently, adding X and/or Z gates):

- Input |00> -> |Phi+> = (|00> + |11>) / sqrt(2)
- Input |01> -> |Psi+> = (|01> + |10>) / sqrt(2)
- Input |10> -> |Phi-> = (|00> - |11>) / sqrt(2)
- Input |11> -> |Psi-> = (|01> - |10>) / sqrt(2)

In general, the H + CNOT circuit acting on input |a b> produces
(|0 b> + (-1)^a |1 (NOT b)>) / sqrt(2).

Example in Qiskit

from qiskit import QuantumCircuit

qc = QuantumCircuit(2, 2)
qc.h(0)        # put qubit 0 into superposition
qc.cx(0, 1)    # entangle qubit 0 with qubit 1
qc.measure([0, 1], [0, 1])

Running this on an ideal simulator gives roughly 50% "00" and 50% "11", and essentially never "01" or "10". On real hardware, noise will show a small number of "01" and "10" results.

Why it matters

Bell states are the basic resource for many quantum protocols, including quantum teleportation, superdense coding, entanglement-based quantum key distribution (such as E91), and tests of Bell inequalities that show quantum correlations cannot be explained by local hidden-variable theories.
