5. Security and privacy model, from the code
5.1 Process and trust boundary
One executable. The interface is embedded at build time (rust-embed over crates/ui/dist) and served through a custom app:// protocol; there is no local web server and no open port. [app/crates/desktop/src/main.rs:1-5, 26-28, 53-69, 364]
The asset handler looks up only the URI path in the embedded map; anything else gets a 404. [app/crates/desktop/src/main.rs:53-69]
The page reaches the host only through window.ipc.postMessage; the host pushes events by calling window.__qe with the event JSON encoded as a string literal, so no event text is interpolated into script code. [app/crates/ui/src/bridge.rs:6-32; app/crates/desktop/src/main.rs:394-397]
The host accepts eight commands (hello, win, save_key, open_key_page, clear_key, set_provider, list_models, ask); malformed JSON and unknown commands are ignored. [app/crates/desktop/src/main.rs:144-149, 277]
IPC origin check: a message is handled only if the request URI host is app.localhost or the scheme is app. [app/crates/desktop/src/main.rs:383-388]
Provider endpoints, key pages and default models are compile-time constants; the page can name a provider only by id, and unknown ids resolve to nothing. [app/crates/desktop/src/llm/mod.rs:25-27, 47-205]
open_key_page opens only a fixed &amp;&apos;static preset URL through ShellExecuteW; an unknown id falls back to the Gemini key page. [app/crates/desktop/src/main.rs:71-81, 192-196]
5.2 Web view lock-down
Navigation is allowed only to https://app.localhost/ and app://localhost/; new-window requests are denied; a drag-drop handler stops dropped files turning into navigations. [app/crates/desktop/src/main.rs:366-369]
DevTools and the default context menus are enabled only in debug builds. [app/crates/desktop/src/main.rs:377, 382]
Browser accelerator keys (reload, print) are not disabled in any build (finding V7). [app/crates/desktop/src/main.rs:370-378; grep, 25 Nov]
The custom protocol is served as https so the page is a secure context. [app/crates/desktop/src/main.rs:374]
Every asset response carries Cache-Control: no-cache and this CSP: default-src &apos;self&apos;; script-src &apos;self&apos; &apos;wasm-unsafe-eval&apos; &apos;unsafe-inline&apos;; style-src &apos;self&apos; &apos;unsafe-inline&apos;; font-src &apos;self&apos;; img-src &apos;self&apos; data:; connect-src &apos;self&apos;. The comment above it says only &apos;wasm-unsafe-eval&apos; is needed (finding H1). The header sets no base-uri, form-action or frame-ancestors directive. [app/crates/desktop/src/main.rs:59-64]
5.3 API keys
Lookup order per provider: Windows Credential Manager (service &quot;QuantumExplainer&quot;, account &quot;&lt;provider&gt;_api_key&quot;), then the provider&apos;s environment variable, then a .env file. [app/crates/desktop/src/config.rs:4-8, 17, 99-106, 127-139]
The app never writes a key to a file: settings.json is a struct with only provider and models, and a unit test checks that a stray api_key field is dropped on re-save. [app/crates/desktop/src/config.rs:2, 21-29, 250-262]
Only the last four characters of a key leave the native process (key_hint in the status event). [app/crates/desktop/src/main.rs:83-116; app/crates/desktop/src/llm/mod.rs:244-248]
Saving a key: format check (20-400 characters, no whitespace or control characters), then a live check with the provider, then storage, then making that provider active; all on a worker thread. [app/crates/desktop/src/main.rs:161-190; app/crates/desktop/src/config.rs:191-199, 210-217]
The key field is type=password with autocomplete off and is cleared as soon as the key is sent to the host. [app/crates/ui/src/main.rs:309-317, 200]
Keys go only in request headers, never in URLs: x-goog-api-key (Gemini), x-api-key (Anthropic), Authorization: Bearer (OpenAI-compatible providers). [app/crates/desktop/src/gemini.rs:53, 103, 119; app/crates/desktop/src/llm/anthropic.rs:63-71; app/crates/desktop/src/llm/openai.rs:95-96, 112, 125]
Errors and notices pass through scrub, which replaces an exact copy of the key with its last four characters (subject to finding K2). [app/crates/desktop/src/llm/mod.rs:250-257, 411-426, 438-456; app/crates/desktop/src/main.rs:188]
Remove deletes the Credential Manager entry; a missing entry counts as success. [app/crates/desktop/src/config.rs:219-227]
.env is git-ignored at the repo root and in app/. A .env file exists at the repo root; its contents were not read. [.gitignore:1; app/.gitignore:5; test -f, 25 Nov]
5.4 Network and TLS
HTTP goes through ureq 3.5.2 with native TLS (SChannel on Windows) and the platform certificate verifier, that is, the OS certificate store. [app/crates/desktop/Cargo.toml:22; app/crates/desktop/src/llm/mod.rs:259-268]
Every preset base URL and key page is https; a unit test enforces it. [app/crates/desktop/src/llm/mod.rs:531]

7. Known limitations and risks visible in code
Windows only. The app uses windows-sys (ShellExecuteW, MessageBoxW), the WebView2 builder extensions and the Windows Credential Manager. On other targets open_in_browser does nothing and fatal() exits without a message. [app/crates/desktop/Cargo.toml:25; app/crates/desktop/src/main.rs:71-81, 304-314, 349-378]
It needs the Microsoft Edge WebView2 Runtime; the startup error message says so. [app/crates/desktop/src/main.rs:323-326]
On Windows 10 there is no Mica backdrop; the page paints its own background. [app/crates/desktop/src/main.rs:355-359]
If LOCALAPPDATA is unset, settings cannot be saved (&quot;LOCALAPPDATA is not set.&quot;) and the WebView2 context gets no data folder. [app/crates/desktop/src/config.rs:41-43, 59; app/crates/desktop/src/main.rs:362]
The Tutor verifier covers only the Bell state, Deutsch-Jozsa with n = 1..3 and 2-qubit Grover; every other question is shown as unverified. [app/crates/qcore/src/lib.rs:408-437; app/crates/ui/src/tutor.rs:263-268]
Atlas circuits are capped at 8 qubits. [app/crates/qcore/src/circuit.rs:14, 184-187]
There is no cancel. Each question runs on a detached thread with up to 4 model calls, timeouts of up to 600 s per attempt and retry waits of 10/30/60 s, so a run can last many minutes. [app/crates/desktop/src/main.rs:268-275; app/crates/desktop/src/llm/mod.rs:296-297; app/crates/desktop/src/llm/openai.rs:13]

Text caps: provider error text is cut to 140 characters, OpenAI refusal text to 200, and Anthropic answers are limited to 16,000 output tokens. [app/crates/desktop/src/llm/mod.rs:293; app/crates/desktop/src/llm/openai.rs:40; app/crates/desktop/src/llm/anthropic.rs:20]
